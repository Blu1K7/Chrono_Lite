# Chrono_Lite  
Lightweight, timestamp-centric OSINT metadata toolkit.

Chrono_Lite provides fast, tamper-aware timestamp extraction for images and videos.  
It is engineered for field analysts, journalists, and security practitioners who need a minimal, reliable, portable toolset without the overhead of full forensic suites.

## Core Features  
- ⚡ Ultra-light metadata parsing (EXIF, XMP, basic video headers)  
- 🕒 Clean, canonical extraction of creation, modification & embedded timestamps  
- 🔒 Tamper-resistant hash workflow (SHA-256)  
- 📤 Minimal export: JSON, TXT, or console output  
- 🧩 Zero external dependencies  

## Philosophy  
Chrono_Lite follows a “precision-first” approach:  
keep the footprint small, remove the noise, surface only what matters.
